### پنل مدیریت قیمت محصولات

یک پروژه مشترک با یکی از دوستانم که برای مدیریت سریع قیمت محصولات یک فروشگاه تجهیزات استخر ساخته شد.

من مسئول بخش Frontend بودم و بخش Backend با Python توسط هم‌تیمی‌ام توسعه داده شد.

این پنل اطلاعات محصولات فروشگاه رو دریافت می‌کنه و امکاناتی مثل:

* جستجوی محصولات
* فیلتر بر اساس دسته‌بندی
* ویرایش قیمت اصلی و قیمت فروش
* انتخاب و ثبت همزمان تغییرات چند محصول

رو فراهم می‌کنه.

هدف اصلی این بود که صاحب فروشگاه بتونه قیمت چندین محصول WooCommerce رو سریع تغییر بده، بدون اینکه مجبور باشه وارد صفحه تک‌تک محصولات در WordPress بشه.

این پروژه در نهایت به صورت فایل EXE آماده و به مشتری تحویل داده شد.
